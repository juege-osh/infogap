# 畅读套餐与贡献福利

2026-10-23起，新购买入口只出售四种畅读套餐。用户段位不再决定阅读、订阅或每日赠分；贡献值保留，用于排行榜和套餐折扣。

| 时长 | 原价 | 情报开放延迟 | 有效天数 |
|---|---:|---:|---:|
| 1个月 | 18元 | 8小时 | 30天 |
| 3个月 | 38元 | 4小时 | 90天 |
| 6个月 | 58元 | 2小时 | 180天 |
| 12个月 | 88元 | 实时 | 365天 |

套餐有效时，已开放的正文与公开原始来源不限次数阅读，不扣积分。套餐阅读不自动生成永久解锁记录。普通用户实时浏览摘要，详情按普通/精选/稀有/独家消耗1/2/4/8积分；积分解锁后可以重复阅读。管理员及审核人员实时查看全部授权内容。内部来源仍按原隐私规则隐藏。

普通用户每日赠送1积分，当日有效。订阅功能由有效畅读套餐提供，最多40条；到期保留配置并暂停。新套餐按现有已付款权益结束时间顺延，不覆盖未使用时长。旧订单的原金额、赠分、支付流水和有效时段保留，不能因为目录停售而拒绝合法迟到回调。

## 贡献折扣

折扣只根据已审核的贡献值计算，购买不增加贡献值。排行榜按贡献值从高到低，同值按注册先后、账号编号排序；测试账号和管理员不参榜。

| 贡献值 | 套餐折扣 |
|---:|---:|
| 0—99 | 原价 |
| 100—299 | 95折 |
| 300—699 | 92折 |
| 700—1399 | 9折 |
| 1400—2499 | 85折 |
| 2500及以上 | 8折 |

支付金额以分为单位整数计算，最后四舍五入一次：`(原价分×折扣百分数+50)/100`。订单保存原价、折扣和实付快照；付款时不按用户后来变化的贡献值重算。积分包不参与套餐折扣。

## 邀请赠分

指定名单首次受邀注册赠1000限时积分，到账起30天有效，不增加贡献值或畅读权益。历史奖励仅把账本能确认的剩余部分移到独立批次；已消费不追扣，购买、贡献等永久积分不变。无法确认的余额保留并记录原因，不能估算扣减。重复启动、注册和回调不重复发放。

解锁优先使用每日赠分，再使用邀请赠分、历史限时赠分，最后使用永久积分。信息证伪时退回原来源：已到期的限时积分不恢复或延期。

## 阅读切换

详情页点击上一条或下一条才尝试解锁，不因打开页面自动扣分。同主题优先，主题读完后先选其他订阅主题，再提示随机主题；本轮已访问条目不重复选。积分不足保留当前页面并提示，不自动购买。有效套餐直接阅读，不扣分或变成永久解锁。

## 后台查看

订单管理支持用户、订单状态和订单号/用户名/邮箱搜索；只读查询不提供补单或修改金额操作。行为记录只保存白名单操作名称、对象编号、响应状态和时间，不记录正文、搜索词、IP或凭据。按北京时间每日整理：次日合并每个用户前一天的明细为一条可展开记录，无行为不生成空记录。合并写入与删除原明细在同一事务中，重复执行不丢失或重复数据。
