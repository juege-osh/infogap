# 全球旅行信息

每条信息只选一个主题。旅行内容选择“出行旅行”，国家、地区和旅行用途都作为标签，再按标签组合筛选；每条合计最多10个标签。国家不限于首批有文章的目的地；没有内容时显示空列表，不用其他国家的文章填充。

常用旅行标签包括签证入境、景点避坑、交通住宿、优惠渠道、支付通信、季节天气、安全提醒。国家与地区用于确定目的地，旅行标签用于区分实际问题。例如日本铁路优惠归入日本、东亚、优惠渠道。

## 写什么

- 景点：是否需要预约、官方售票入口、闭馆日、附加费用和容易误解的规则。
- 优惠：谁能用、在哪里买、包含什么、不包含什么、有效期及总成本。官方通票不一定比单买便宜，不能替所有路线下结论。
- 入境：按国籍、护照、出行目的和停留时间说明适用范围，保留官方规则和核验日期。
- 交通住宿：购票条件、退改规则、机场或跨城交通、入住限制与必要税费。
- 支付通信：当地付款方式、现金需求、官方通信方案及使用限制。
- 天气安全：注明地点、季节和发布时间，短期预警不能当成长期旅行结论。

官方规则与成员经历分开表述。“我在某日遇到”的经验只代表当次经历，不能改写成当地普遍做法；景点踩坑可以整理已核验的预约、收费与退改规则，不编造亲历。

## 内容与权益

免费摘要应让读者先知道目的地、核心用途及主要限制，详细步骤按原有额度规则解锁。来源日期与本站审核发布时间分别保留；管理员立即查看全部，其他成员仍按段位延迟。

发布前核验官方页面、关键条件和时效。常设指南若未标注原始发布日期，保留空日期并记录本次核验时间；本站发布按当前时间计时，不把核验日期伪装成来源发布日期。价格、优惠、签证及预约政策发生变化时修订正文；已失效的活动标记失效。未确认长期有效的服务，不写“永久”“随时可用”。

内部复用标签保存国家、地区和旅行标签；页面展示普通中文名称。搜索、筛选、投稿和后台编辑共用这份信息，不增加独立的旅行会员或收费规则。
