# InfoGap · 前沿情报站

邀请制的信息社区，跟进 Nature、Science、GitHub、研究机构与政府部门的公开进展，覆盖科学技术、产业、政策和生活等 28 个主题。

网站：<https://infogap.osh.lol>

## 使用规则

每条信息差只能选择一个主题，可添加最多10个标签。国家、地区、旅行用途等标注也计入标签总数。

每条信息都有“等级-主题-全站序号”编号，例如 `JX-AI-116` 表示人工智能主题的精选信息，`PT-LX-205` 表示旅行普通信息，`XY-WL-08` 表示物理稀有信息。数字至少两位，超过99后正常增长，不因排序、分页、审核状态或分类调整而重排。

- 新成员需邀请码，验证邮箱并填写用户名后自动登录、进入首页。站长邮箱单独验证，成功后自动授予站长角色并进入管理工作台。
- 新成员初始永久积分为 0，每日赠额按段位领取；普通、精选、稀有、独家内容分别消耗 1、2、4、8 点。摘要可直接阅读，详情与原始来源按权限解锁。指定活动邀请码的名单内新成员，可在验证邮箱并注册成功后一次性领取配置的永久积分与限时青铜权益，规则见 `docs/invite-campaigns.md`。
- 有效投稿审核通过后获得 100 点长期额度。每天按段位赠送 1/2/3/5/8/10/15/20/30/50 点，北京时间零点刷新，不累积。先用每日额度，再用长期额度；重复阅读不扣额度。
- 高级内容同时要求段位和质量贡献记录。所有成员都能提交高质量内容。
- 自动采集默认只接收最近180天且有明确发布日期的条目，生成待审核候选；来源数量不代表内容已经核实。预印本与同行评审论文分别标注。
- 高级内容在服务器检查权限，浏览器不会提前收到被锁定的正文。

生活与机会栏目单列省钱优惠、招聘求职、生活实用、职业成长、住房居住、出行旅行、商业创业。旅行可按国家、地区和旅行标签查找，具体内容规范见 [全球旅行信息](docs/travel.md)。

## 本地运行

需要 Go 1.26 和 Python 3.6 以上。服务端用 SQLite 保存账号、额度、内容与审核记录。

```sh
go test ./...
go run . -addr 127.0.0.1:18869 -db state/infogap.sqlite -web web
```

邮箱发送需要在环境中配置 `SMTP_HOST`、`SMTP_PORT`、`SMTP_USER`、`SMTP_PASSWORD`、`SMTP_FROM` 和 `SMTP_SECURITY`。生产设置 `INFOGAP_PUBLIC_URL=https://infogap.osh.lol`。密钥、验证码、用户数据和数据库不提交到仓库。

接口见 `API.md`，来源与采集说明见 `docs/sources.md`。`deploy/` 包含独立站点服务、采集定时器、每日备份和反向代理配置。

普通订阅、浏览器读取、去重和候选入库均由固定程序完成，不调用模型，采集本身不消耗模型 token。浏览器采集使用独立容器，读取正常渲染后的公开页面，采集结果仍需审核。X 只使用 `data/x-accounts.json` 中启用的可信账号，同时要求帖子有一手证据链接；营销、带货和无依据转述不入库。具体规则见 `docs/x-sources.md`。

社区出处可以设为仅后台可见，普通成员的列表、正文、搜索与订阅均隐藏出处，站长和审核员可追溯原始资料。公开论文及官方网站继续保留引用链接。

长于 2000 字的新增原文进入独立精炼队列，固定使用 `gpt-6.1-sol`、轻度推理，输出面向普通读者的中文草稿，正文含出处不超过 2000 字。短内容不调用模型，同一原文按指纹缓存；每轮最多 3 篇、每天最多 8 次尝试，单篇最多尝试 3 次。草稿仍须审核，人工编辑不会被自动覆盖。详见 `docs/codex-server.md`。

## 部署约定

代码按版本放在 `/opt/infogap-osh/releases/`，`current` 指向正在运行的版本。数据库独立保存在 `/var/lib/infogap-osh/`，更新代码不会覆盖成员数据。每日备份写入 `/var/backups/infogap-osh/`，备份不属于公开网站目录。

发布前检查权限、额度事务、邮件发送、采集状态、HTTPS 和手机页面；旧版本保留供回滚。前端仅展示文本、排版与界面图标，不依赖外部字体或图片。

站长与指定审核员立即查看全部内容、免阅读额度。站长管理邀请码、用户、会员、采集源及全部内容状态。只有指定站长邮箱经过验证才能获得站长身份。

长期阅读额度可单独购买：100点9.90元、350点29元、1000点79元。购买不增加段位或质量贡献。阅读额度与效率会员均只支持支付宝付款。

效率会员为30天9.90元、365天99元，非自动续费，提供至少20条订阅配置。购买不提升段位、不增加解锁额度、不缩短内容延迟，也不绕过稀有/独家内容的贡献门槛。会员到期保留订阅配置，超出当前段位额度的配置暂停。支付参数只从服务器环境读取，独立回调地址以站点域名为准，详见 `docs/billing.md`。

## 发布与核验

`deploy/install.sh` 接收已上传到服务器的版本目录，先备份现有数据库，再切换独立服务、配置站点及启动采集/备份定时器。构建时用 `-X main.buildCommit=<commit>` 注入版本，公开 `/healthz` 可核对代码版本。

反向代理只信任Cloudflare公布的IP范围及本机受信反向代理网络，避免登录限流把所有成员算作同一个代理地址。范围来源：[IPv4](https://www.cloudflare.com/ips-v4/)、[IPv6](https://www.cloudflare.com/ips-v6/)，发布时需复核。

修改前端后同步更新 `web/index.html` 的脚本和样式版本参数，避免浏览器或 CDN 继续使用上一版界面。HTML 本身不缓存。

## 测试用户与功能自检

站长登录后，可从顶部或左侧进入“测试用户模式”，选择黑铁到王者的段位、测试额度、会员权益和贡献条件。测试使用独立账号，底部始终保留“返回管理员”。阅读、收藏和订阅会按普通用户规则执行；真实站长数据保持独立。

“功能自检”支持单独检查服务配置、登录权限、内容额度、订阅和支付，也可一键全检并复制结果。业务检查使用内存数据库，不发送真实邮件、不连接支付网关。正式接口报错时显示问题编号，可用相同编号在服务器日志中定位。

管理员还可在自检页生成 **¥0.01 支付宝真实付款码**。这是实际收款订单，需要付款者扫码；成功后只记录支付结果，不发放任何权益。模拟检查通过不能替代这一步真实付款验收。
